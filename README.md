# Halli Santhe - Village Marketplace 🌾

Halli Santhe is a dedicated Android application designed to bridge the gap between local rural artisans and modern buyers. The name **"Halli Santhe"** (meaning "Village Market") reflects our mission to bring the authentic charm and craftsmanship of rural India to a digital platform.

## 🚀 Features

- **Artisan Empowerment**: 
  - Artisans can create and manage their professional profiles.
  - Easy product upload with image support and detailed descriptions.
  - "My Crafts" dashboard to track listed items.
- **Seamless Buyer Experience**:
  - Explore a wide variety of authentic village products categorized for easy navigation.
  - Detailed product views with cinematic layouts.
  - Direct communication options (WhatsApp/Call integration) for personalized transactions.
- **Secure Authentication**: 
  - Dedicated Login and Registration flows for both artisans and buyers.
- **Robust Backend**: 
  - Powered by **Supabase** for real-time data management and secure storage.

## 🛠️ Technology Stack

- **Platform**: Android
- **Language**: Kotlin
- **Database & Auth**: Supabase
- **UI Design**: Modern XML-based layouts with a focus on cinematic UX.

## 📂 Project Structure

- `app/src/main/java/com/example/hallisantheapp/`
  - `ArtisanProfileActivity.kt`: Profile management for sellers.
  - `ArtisanUploadActivity.kt`: Interface for listing new crafts.
  - `BuyerHomeActivity.kt`: Main feed for discovery.
  - `ProductDetailActivity.kt`: Interactive product insights.
  - `SupabaseClient.kt`: Backend configuration.

## 🏁 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shettyprerna2607/Halli-Santhe.git
   ```
2. Open the project in **Android Studio**.
3. Ensure you have the necessary Supabase credentials in `SupabaseClient.kt` or `local.properties`.
4. Build and run the app on an emulator or physical device.
